# Regla de Comunicación: Preguntar antes de especular

Cuando se presente un bug, error visual o comportamiento inesperado:
- Si falta información puntual (como mensajes de error de la consola, contexto de sesión, o datos específicos de lo que está viendo el usuario), **pregúntale directamente al usuario** de forma clara y concisa.
- **Evitar especular** o buscar a ciegas por toda la aplicación cuando una simple pregunta al usuario puede aclarar de inmediato el estado actual o la causa raíz.
- Priorizar la confirmación directa del usuario para avanzar de forma más rápida y precisa.
